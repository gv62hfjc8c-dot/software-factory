# Roles

## Product Owner

Define objetivos.

Define prioridades.

Aceita funcionalidades.

---

## Software Architect

Define arquitetura.

Define padrões.

Revê decisões técnicas.

---

## Frontend Developer

Implementa interface.

Segue arquitetura.

---

## Backend Developer

Implementa lógica de negócio.

Implementa APIs.

---

## Code Reviewer

Revê código.

Identifica melhorias.

Não implementa funcionalidades.
