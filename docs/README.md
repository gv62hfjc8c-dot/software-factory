# Software Factory

## Objetivo

A Software Factory é um sistema de desenvolvimento criado para garantir que todos os projetos seguem os mesmos padrões de qualidade, arquitetura e documentação.

Não é um projeto de software.

É um repositório que contém o método utilizado para desenvolver qualquer aplicação.

---

# Princípios

Todo o desenvolvimento deve ser:

- Modular
- Escalável
- Bem documentado
- Versionado com Git
- Orientado a arquitetura
- Fácil de manter
- Independente das ferramentas utilizadas

# Documentação

Toda a documentação obrigatória encontra-se na pasta docs.

Nenhum desenvolvimento deve começar sem que exista documentação suficiente.

---

# Filosofia

A arquitetura controla o desenvolvimento.

O desenvolvimento nunca controla a arquitetura.
