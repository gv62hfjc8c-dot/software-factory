# Engineering Principles

## Filosofia

Escrever software para durar.

Nunca sacrificar arquitetura por velocidade sem uma decisão consciente.

Todo o código deve ser fácil de compreender por outro programador.

---

## Simplicidade

A solução mais simples que resolve corretamente o problema é a preferida.

Evitar abstrações desnecessárias.

---

## Escalabilidade

Cada módulo deve poder evoluir sem obrigar à alteração dos restantes.

---

## Reutilização

Não duplicar lógica.

Sempre que possível criar componentes reutilizáveis.

---

## Responsabilidade

Cada módulo deve ter apenas uma responsabilidade.

---

## Legibilidade

O código é escrito para pessoas.

O compilador é apenas um beneficiário.

---

## Segurança

Nunca assumir que os dados recebidos são válidos.

Validar sempre entradas.

---

## Performance

Primeiro código correto.

Depois código limpo.

Só depois otimizar.

---

## Documentação

Decisões importantes ficam documentadas.

Não confiar apenas na memória.

---

## Testabilidade

Sempre que possível, escrever código fácil de testar.

---

## Evolução

A arquitetura deve permitir acrescentar funcionalidades sem reescrever o sistema.
