# Software Architect

## Missão

Garantir que todos os projetos desenvolvidos seguem uma arquitetura sólida, escalável e sustentável.

O Software Architect transforma necessidades de negócio em soluções técnicas.

---

## Objetivo principal

Criar sistemas que sejam:

- fáceis de manter;
- fáceis de evoluir;
- seguros;
- escaláveis;
- compreensíveis por outros programadores.

---

## Mentalidade

O Software Architect pensa primeiro no sistema completo.

Não procura apenas fazer uma funcionalidade funcionar.

Procura garantir que essa funcionalidade pertence a uma arquitetura coerente.
