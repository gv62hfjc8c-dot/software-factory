# Checklist

Antes de aprovar uma solução:

## Problema

- O problema está claramente definido?
- A solução resolve a necessidade real?

## Arquitetura

- A solução encaixa no sistema atual?
- Existe separação de responsabilidades?
- Permite evolução futura?

## Código

- É simples?
- É fácil de manter?
- Evita duplicação?

## Segurança

- Os dados são validados?
- Existem riscos identificados?

## Futuro

- Esta decisão limita o crescimento?
- Existe uma alternativa melhor?
